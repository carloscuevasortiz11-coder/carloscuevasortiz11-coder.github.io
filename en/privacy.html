Privacy Policy

Last updated: September 27, 2026

This policy explains what data the "Cementerio de Marcas" application (the "application") and this website process, why, and how you can revoke access or request deletion.

1. Who is responsible

The controller is the owner of the YouTube channel Cementerio de Marcas. Contact: carloscuevasortiz11@gmail.com.

2. What the application is and who uses it

The application is an internal tool that runs on the channel owner's computer. It produces documentaries about failed brands and uploads them to the channel's own accounts. It is not a public service: there is no user sign-up, and the only account ever authorized is the channel owner's.

3. Google and YouTube data

What it accesses

The application requests a single Google scope: https://www.googleapis.com/auth/youtube.upload ("Manage your YouTube videos"). It uses it only to:

  • Upload videos to the authorized channel, with their title, description, tags, category, language and the altered or synthetic content disclosure.
  • Schedule the publish time of those videos.
  • Upload the thumbnail for those videos.

Videos are always uploaded as private. They are scheduled to go public at least 24 hours after upload, so the owner reviews them in YouTube Studio and can change them or cancel their publication before that time.

The application does not read or store comments, subscribers, analytics, watch history, playlists, email, contacts or any data about other YouTube users.

How it is stored

After authorization, Google issues an access token to the application. That token is stored only on the owner's computer, in a local file that is never uploaded to any server or shared. The application has no servers or cloud database of its own.

The token is kept until access is revoked or the file is deleted. Video data (titles, descriptions, thumbnails) is content created by the channel itself.

Who it is shared with

No one. Data obtained from Google APIs is not sold, not transferred to third parties, not used for advertising and not used to train artificial intelligence models. It is only sent to Google, through the YouTube API, to upload the videos.

Limited Use

The application's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

How to revoke access

You can revoke access at any time from the third-party apps with account access page of your Google Account (also available through Google security settings). Once revoked, the stored token stops working, and the owner also deletes it from the computer.

4. TikTok data

When TikTok publishing is enabled, the application will use the TikTok Content Posting API only to send the channel's short videos to the owner's own TikTok account. For this it needs the basic account information TikTok provides on authorization (user ID, display name and avatar) and the permission to post videos.

As with Google: the token is stored only on the owner's computer, data is not shared or sold, and no data about other users is accessed. The TikTok Terms of Service and Privacy Policy apply. Access can be revoked from the TikTok account's security settings, under connected apps and services.

5. Other services used by the application

To create the videos, the application queries external services. None of them receives Google, YouTube or TikTok data, or any personal data: only the name of the brand covered, the script text or image search terms.

  • DeepSeek: writing the script and texts.
  • Microsoft Edge text-to-speech: narration.
  • Wikimedia Commons, Pexels and Pixabay: searching for freely licensed photographs.

6. This website

This website uses no cookies, analytics, advertising or forms, and collects no data from its visitors. It is hosted on GitHub Pages; GitHub may log visitors' IP addresses for security purposes, as described in the GitHub General Privacy Statement.

If you email us, we will use your address and message only to reply, and delete them when no longer needed.

7. Children

The application is not directed at children and does not process children's data.

8. Your rights

Under the General Data Protection Regulation (GDPR), you can request access, rectification, erasure, restriction of or objection to processing, and portability of your data by writing to carloscuevasortiz11@gmail.com. You can also file a complaint with the Spanish Data Protection Agency (AEPD).

9. Changes

If this policy changes, the new version will be published here with a new update date.
