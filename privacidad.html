Política de privacidad

Última actualización: 27 de septiembre de 2026

Esta política explica qué datos trata la aplicación «Cementerio de Marcas» (en adelante, «la aplicación») y este sitio web, para qué, y cómo puedes revocar el acceso o pedir que se borren.

1. Quién es el responsable

El responsable es el titular del canal de YouTube Cementerio de Marcas. Contacto: carloscuevasortiz11@gmail.com.

2. Qué es la aplicación y quién la usa

La aplicación es una herramienta interna que se ejecuta en el ordenador del titular del canal. Genera documentales sobre marcas que fracasaron y los sube a las cuentas del propio canal. No es un servicio público: no hay registro de usuarios y la única cuenta que se autoriza es la del titular.

3. Datos de Google y YouTube

A qué accede

La aplicación solicita un único permiso de Google: https://www.googleapis.com/auth/youtube.upload («Administrar tus videos de YouTube»). Con él solo hace esto:

  • Subir videos al canal autorizado, con su título, descripción, etiquetas, categoría, idioma y la declaración de contenido alterado o sintético.
  • Programar la hora de publicación de esos videos.
  • Subir la miniatura de esos videos.

Los videos se suben siempre como privados. Se programan para publicarse al menos 24 horas después de la subida, de modo que el titular los revisa en YouTube Studio y puede cambiarlos o cancelar su publicación antes de esa hora.

La aplicación no lee ni guarda comentarios, suscriptores, estadísticas, historial, listas de reproducción, correo, contactos ni ningún dato de otros usuarios de YouTube.

Cómo se guardan

Tras autorizarla, Google entrega a la aplicación un token de acceso. Ese token se guarda únicamente en el ordenador del titular, en un archivo local que no se sube a ningún servidor ni se comparte. La aplicación no tiene servidores propios ni base de datos en la nube.

El token se conserva hasta que se revoca el acceso o se borra el archivo. Los datos de los videos (títulos, descripciones, miniaturas) son contenido creado por el propio canal.

Con quién se comparten

Con nadie. Los datos obtenidos de las API de Google no se venden, no se ceden a terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial. Solo se envían a Google, a través de la API de YouTube, para subir los videos.

Uso limitado

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

YouTube y Google

La aplicación usa los servicios de API de YouTube. Al usarla se aplican los Términos de servicio de YouTube y la Política de privacidad de Google.

Cómo revocar el acceso

Puedes retirar el acceso en cualquier momento desde la página de aplicaciones con acceso a tu cuenta de Google (también en la configuración de seguridad de Google). Al revocarlo, el token guardado deja de funcionar; además, el titular lo borra del ordenador.

4. Datos de TikTok

Cuando se active la publicación en TikTok, la aplicación usará la API de publicación de contenido de TikTok (Content Posting API) solo para enviar los videos cortos del canal a la cuenta de TikTok del titular. Para ello necesita la información básica de la cuenta que TikTok entrega al autorizarla (identificador de usuario, nombre visible y avatar) y el permiso para publicar videos.

Igual que con Google: el token se guarda solo en el ordenador del titular, los datos no se comparten ni se venden y no se accede a datos de otros usuarios. Se aplican los Términos de servicio y la Política de privacidad de TikTok. El acceso se revoca desde los ajustes de seguridad de la cuenta de TikTok, en el apartado de aplicaciones y servicios conectados.

5. Otros servicios que usa la aplicación

Para crear los videos, la aplicación consulta servicios externos. Ninguno recibe datos de Google, YouTube, TikTok ni datos personales: solo el nombre de la marca tratada, los textos del guion o términos de búsqueda de imágenes.

  • DeepSeek: redacción del guion y de los textos.
  • Microsoft Edge (texto a voz): narración.
  • Wikimedia Commons, Pexels y Pixabay: búsqueda de fotografías con licencia libre.

6. Este sitio web

Este sitio no usa cookies, analítica, publicidad ni formularios, y no recoge datos de sus visitantes. Está alojado en GitHub Pages; GitHub puede registrar la dirección IP de las visitas por motivos de seguridad, según la declaración de privacidad de GitHub.

Si nos escribes por correo, usaremos tu dirección y tu mensaje solo para responderte y los borraremos cuando ya no hagan falta.

7. Menores

La aplicación no está dirigida a menores ni trata datos de menores.

8. Tus derechos

Conforme al Reglamento General de Protección de Datos (RGPD), puedes pedir el acceso, la rectificación, la supresión, la limitación u oposición al tratamiento y la portabilidad de tus datos escribiendo a carloscuevasortiz11@gmail.com. También puedes reclamar ante la Agencia Española de Protección de Datos.

9. Cambios

Si esta política cambia, se publicará aquí con una nueva fecha de actualización.
